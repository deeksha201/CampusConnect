# Campus Connect

Campus Connect is a modern lost-and-found platform built for college campuses. Students, staff, and campus support teams can report lost or found items, browse listings, search for specific belongings, and mark items as returned. The app is designed to make item recovery faster, easier, and more organized through a clean, responsive, and user-friendly interface.

**Live app**: https://github.com/deeksha201/CampusConnect.git




## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd CampusConnect
npm i
npm run dev
```
